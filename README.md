# AVERON Parser

Отдельный сервис поиска товаров для AVERON. Первый источник — **1688**.

Сервис принимает человеческий запрос на русском или узбекском, превращает его в китайский поисковый запрос, открывает 1688 через реальный браузер, нормализует карточки и сохраняет результат в `data/`. Все найденные товары получают статус `PENDING_REVIEW`: AI и парсер ничего не публикуют автоматически.

## Быстрый запуск

```powershell
Copy-Item .env.example .env
npm install
npx playwright install chromium
npm run dev
```

Откройте <http://127.0.0.1:4318>.

Если на компьютере установлен Google Chrome, значение `BROWSER_CHANNEL=chrome` использует его. Если нужен Chromium от Playwright, оставьте `BROWSER_CHANNEL` пустым.

## Авторизация 1688

1688 иногда показывает вход или CAPTCHA. Тогда:

1. Установите в `.env` `HEADLESS=false`.
2. Перезапустите сервис.
3. Нажмите «Открыть 1688 для входа».
4. Войдите вручную в открывшемся Chrome.
5. Повторите поиск.

Сессия хранится локально в `.browser-profile/` и не попадает в Git. Сервис не обходит CAPTCHA и не хранит пароль.

## AI

AI необязателен. Без него работает встроенный словарь популярных товарных терминов. Для более точного поиска укажите OpenAI-совместимый API:

```env
AI_BASE_URL=http://localhost:11434/v1
AI_API_KEY=ollama
AI_MODEL=qwen2.5:7b
```

Подходит локальный Ollama или другой совместимый провайдер. При недоступности модели сервис автоматически возвращается к встроенному разбору.

## API

- `GET /api/health` — состояние сервиса.
- `POST /api/search` — поиск: `{ "query": "черная мужская худи", "minPriceCny": 20, "maxPriceCny": 80, "limit": 24 }`.
- `POST /api/product` — импорт конкретной карточки: `{ "url": "https://detail.1688.com/offer/..." }`.
- `GET /api/search/:id` — сохранённый результат.
- `POST /api/session/open` — открыть 1688 для ручного входа.

## Ограничения MVP

- Разметка 1688 меняется; селекторы вынесены в отдельный адаптер `src/adapter-1688.ts`.
- Некоторые аккаунты/регионы получают обязательную проверку 1688.
- Цена на карточке может быть диапазоном или зависеть от количества; перед импортом её обязан проверить администратор.
- Следующий этап интеграции — отправка выбранной карточки в импорт-очередь основного AVERON backend.
